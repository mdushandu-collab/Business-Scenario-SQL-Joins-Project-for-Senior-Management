https://tv-growth-lens.lovable.app/ --** BrightTV Smart Dashboard. 

This project demonstrates an end-to-end data analytics solution designed to help BrightTV's CEO achieve the strategic objective of growing the company's subscriber base during the current financial year. Working from the business problem defined in the case study, the project followed the complete analytics lifecycle: data cleaning, exploration, visualization, insight generation, and executive recommendations.

The planning and mission was drafted using Miro planning to unpack the business problems in order provide soluable insights. The time frame associated in execution was designed by using a gantt chart.
The raw viewership dataset was transformed into a clean, analysis-ready dataset using SQL and Databricks, ensuring accurate reporting through data validation, feature engineering, and the conversion of UTC timestamps to South African time. Exploratory Data Analysis (EDA) was performed to identify trends in subscriber behaviour, viewing patterns, demographics, regional engagement, channel popularity, genres, and screen-time consumption.

A structured analytics roadmap was developed to align the CEO's business objective with the data analyst's role and a series of data-driven questions that guided the investigation. This framework ensured every analysis directly supported executive decision-making and the Customer Value Management (CVM) team's subscriber growth strategy.

An interactive dashboard was then built in Looker Studio to provide executives with real-time insights into key performance indicators, including total subscribers, active subscribers, regional viewership, demographic engagement, channel performance, age-group consumption, and content preferences. The dashboard highlights that only 43.9% of subscribers are active viewers, revealing a significant opportunity to increase engagement within the existing customer base before pursuing new subscriber acquisition. This dashboard was also converted into a smart dashboard for the CVM team to engage the data effectively.

The project concludes with actionable business recommendations, including targeted regional marketing, investment in high-performing live content, personalized engagement strategies for high-value demographic groups, and initiatives to improve viewing activity on low-consumption days. Together, the analytics roadmap, executive dashboard, and strategic recommendations provide a practical decision-support solution that enables BrightTV's leadership to make informed, data-driven decisions aimed at increasing subscriber engagement, retention, and long-term business growth.
